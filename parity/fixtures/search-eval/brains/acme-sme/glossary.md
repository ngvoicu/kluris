# Glossary

Project-specific terms, acronyms, and conventions.

| Term | Meaning |
|------|---------|
| DLQ | Dead-letter queue: where a background job lands after its last retry fails |
| NamedParameterJdbcTemplate | Spring's JDBC helper we use for every query instead of an ORM |
| Booking | One scheduled appointment between a client and a practitioner |
| Practitioner | The person who runs a session; also called provider in old code |

**Drill** - a scheduled restore of last night's backup into a scratch server
**Freeze** - the two days before a release when only fixes are merged
