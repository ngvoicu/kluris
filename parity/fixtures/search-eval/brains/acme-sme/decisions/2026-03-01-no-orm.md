# Raw SQL instead of an ORM

## Decision

All database access uses hand-written SQL through Spring's
`NamedParameterJdbcTemplate`. We do not use JPA or Hibernate.

## Why

Lazy loading caused N+1 query storms on the calendar page, and the generated
SQL was hard to review. Plain SQL keeps every query visible in code review and
lets us use Postgres features (CTEs, `ON CONFLICT`) directly.

## Consequences

Mapping rows to objects is manual: each repository has a small `RowMapper`.
Migrations are plain SQL files run by Flyway.
